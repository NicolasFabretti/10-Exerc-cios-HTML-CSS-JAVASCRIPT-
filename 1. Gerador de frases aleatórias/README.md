#Gerador de Frases Motivacionais

Um projeto simples em HTML, CSS e JavaScript que exibe frases motivacionais aleatórias sempre que o usuário clica no botão “Nova frase”.

Funcionalidades

Exibe uma frase motivacional na tela.
Gera uma frase diferente a cada clique.
Evita repetir a mesma frase consecutivamente.
Layout responsivo com design simples e agradável.

Como funciona?

O arquivo JavaScript contém:
Um array com várias frases.
Um sistema que sorteia um índice aleatório.
Uma verificação para não repetir a mesma frase duas vezes seguidas.
Atualização do texto na tela com innerText.

HTML
Estrutura básica com título e botão.

CSS
Layout centralizado, cores suaves e tipografia agradável.

JavaScript
Lógica de sorteio e exibição da frase usando Math.random() e addEventListener.
