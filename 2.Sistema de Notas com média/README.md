Sistema de Notas com Média

Este projeto é um sistema simples de cálculo de média escolar, desenvolvido com HTML, CSS e JavaScript, onde o usuário insere três notas e o sistema calcula automaticamente a média ao clicar em um botão.

O objetivo principal do projeto é praticar manipulação do DOM, eventos, funções e lógica básica em JavaScript, além de estilização com CSS.

Funcionalidades

Inserção de 3 notas;
Cálculo automático da média aritmética;
Resultado exibido na tela com 1 casa decimal;
Interface simples e estilizada;
Validação básica para conversão de valores numéricos.
