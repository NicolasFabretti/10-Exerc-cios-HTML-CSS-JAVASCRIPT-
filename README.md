# 10-Exercicios-HTML-CSS-JAVASCRIPT

Guia Completo — 10 Exercícios de HTML, CSS e
JavaScript (Do Iniciante ao Avançado)


1. Gerador de Frases Aleatórias
Objetivo: Criar um botão que exibe frases aleatórias na tela.
O que você treina: DOM básico, Math.random(), eventos.
Dicas de JS: Array de frases, innerText, addEventListener.
Dicas de HTML/CSS: Use um botão e uma caixa onde a frase aparecerá.

2. Sistema de Notas com Média
Objetivo: Inserir 3 notas e calcular média, com resultado aprovado/reprovado.
O que você treina: Condições, Number(), manipulação de classes.
Dicas de JS: if/else, validação, innerHTML.
Dicas de HTML/CSS: Campos numéricos, cores para feedback (verde/vermelho).

3. Relógio Digital + Tema Dark/Light
Objetivo: Relógio em tempo real e botão para alternar tema.
O que você treina: Date(), setInterval(), toggle.
Dicas de JS: Atualizar hora a cada 1s, salvar tema em localStorage.
Dicas de HTML/CSS: Corpo com classe .dark para trocar tema.

4. To-Do List Simples com LocalStorage
Objetivo: Criar lista de tarefas persistente.
O que você treina: Arrays, eventos, localStorage.
Dicas de JS: map(), filter(), classList.add/remove.
Dicas de HTML/CSS: Lista estilizada, estado concluído com line-through.

5. Calculadora Simples
Objetivo: Criar interface estilo calculadora com operações básicas.
O que você treina: Funções, estrutura lógica, eventos.
Dicas de JS: Nada de eval(); manipule números manualmente.
Dicas de HTML/CSS: Grid de botões.

6. Quiz com Pontuação
Objetivo: Quiz com perguntas, alternativas e resultado final.
O que você treina: Arrays de objetos, loops, DOM dinâmico.
Dicas de JS: forEach, criação de elementos, controle de estado.
Dicas de HTML/CSS: Barra de progresso, caixa de pergunta.

7. Slider/Carrossel Automático
Objetivo: Criar slider que muda automaticamente.
O que você treina: setInterval(), CSS com translateX.
Dicas de JS: Índice atual + movimentação de slides.
Dicas de HTML/CSS: Layout flex horizontal, overflow hidden.

8. Jogo Pedra, Papel e Tesoura
Objetivo: Usuário escolhe; computador sorteia; mostrar vencedor.
O que você treina: Aleatoriedade, comparação lógica.
Dicas de JS: Math.random(), funções para regras.
Dicas de HTML/CSS: Ícones visuais e feedback colorido.

9. CRUD de Usuários (sem backend)
Objetivo: Criar, editar, deletar e listar usuários.
O que você treina: Manipulação completa do DOM, arrays de objetos, modularização.
Dicas de JS: Funções puras → create, read, update, delete.
Dicas de HTML/CSS: Tabela ou cards responsivos.

10. App de Previsão do Tempo (API externa)
Objetivo: Consumir API e exibir temperatura, clima e ícone.
O que você treina: fetch(), async/await, JSON, tratamento de erros.
Dicas de JS: try/catch, mensagens de erro amigáveis.
Dicas de HTML/CSS: Layout responsivo, animação fade-in ao carregar dados.
